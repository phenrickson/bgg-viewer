# bgg-viewer

A SvelteKit front-end for BGG data — flexible catalog browse/search plus
model enrichments (predictions, similarity, embeddings). Consumes the decoupled
warehouse read API in `bgg-data-warehouse`. Eventually replaces `bgg-dash-viewer`.

Built from the conventions in the `front-end-design` starter kit (copied into
`.claude/skills/` and owned here).
