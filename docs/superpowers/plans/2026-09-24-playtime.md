# Play time in the catalog, Explore and Discover — plan

**Spec:** `docs/superpowers/specs/2026-09-24-playtime-design.md`
**Branch:** `feat/catalog-playtime` from `main`. One PR, `feat(catalog): play time in the catalog, Explore and Discover`. Phil merges.

## Goal

The catalog carries `min_playtime`, `max_playtime`, `time_per_player`; Explore and Discover
filter on play time through a shared `Scope` field that round-trips in the URL.

## Steps (one commit each)

### 1. Catalog columns — `feat(catalog): carry play time`

- `columns.ts`: `min_playtime: 'int'`, `max_playtime: 'int'`, `time_per_player: 'float32'` in
  `SCALAR_COLUMNS`.
- `catalogQuerySql`: the three are not plain `f.<col>` — emit
  `NULLIF(f.min_playtime, 0) AS min_playtime`, `NULLIF(f.max_playtime, 0) AS max_playtime`,
  `SAFE_DIVIDE(NULLIF(f.max_playtime, 0), NULLIF(f.max_players, 0)) AS time_per_player`
  (the model's rule: NULL when either is 0/NULL). A small map of per-column SQL
  expressions, defaulting to `f.<col>`, so the SELECT and the schema still come from one list.
- Tests (`columns.test.ts`): the three names are in `SCALAR_NAMES`; the SQL carries the
  NULLIF / SAFE_DIVIDE expressions.

**Verify:** `just check`, `just test`; dry-run the catalog query (bytes, should stay ~same);
build the artifact locally with `--dry-run` publish.

### 2. Scope — `feat(scope): a play-time range`

- `scope.ts`: `playtimeMin`, `playtimeMax` (null default) on `Scope` / `DEFAULT_SCOPE`;
  `scopeToParams` / `scopeFromParams` as `tmin` / `tmax`; `toWhere` →
  `max_playtime >= n` / `max_playtime <= n`; `activeFilters` chip via the existing `range()`
  helper.
- Tests (`scope.test.ts`): round-trip, WHERE text, chip label and clear patch, and that the
  map's `writeMapUrl` doesn't collide.

**Verify:** `just test`.

### 3. Explore rail — `feat(explore): filter by play time`

- `Rail.svelte`: a Play time group beside player count using the rail's range-slider
  component, stops 15 / 30 / 45 / 60 / 90 / 120 / 180 / 240+ (top stop = no upper bound).

**Verify:** `just check`; Phil on `just dev` — slider writes `tmin`/`tmax`, chips appear and
clear, counts move; light + dark.

### 4. Discover dial — `feat(discover): a play-time dial`

- Query chip counts for the proposed bands against the catalog first (like the category
  chips' comment records); adjust edges if one band dominates.
- `dials.ts`: `PLAYTIME_CHIPS` + `isPlaytimeOn` / `playtimePatch`; update the "keep this list
  short" comment to record the fourth dial as Phil's call.
- `DialStrip.svelte`: a fourth row. Labels `PLACEHOLDER(Phil)`.
- Tests (`dials.test.ts`): patch/on-state per chip.

**Verify:** `just check`, `just test`; Phil on `just dev` — Discover and "see all in Explore"
carry the same play-time filter.
